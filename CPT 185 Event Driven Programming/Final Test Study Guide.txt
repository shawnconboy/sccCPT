		numbers.Add(2);
		numbers.Add(10);

Lists Vs Array
	A List is better than an array when you don't know the number of

Classes
	A class is a blueprint for creating objects. 
	It defines the data (properties) and behaviors (methods) that the object will have.
	
	How to declare a class
		public class Person
		{
			// this bittie right here is technically a declaration
		}
	
	Write constructors
		A constructor is a special method that runs automatically when an object
		is created and initializes the object's fields or properties.
		
		Default Constructor
		Paratemerized Constructor
		
	Properties
		A property is a class member that controls access to a field. It holds data about
		the object through get / set accessors.
		
	Fields
		A field is a variable that belongs to the class.
		It holds data about the object through get / set accessors
		
	Methods associated with class
		Methods define what actions the object can perform.
		
		public void Speak()    					// method
		{
			Console.WriteLine("Hello");
		}

		
	Encapsulation
		Protects data inside a class by
			Making fields private
			Exposing them safely through public properties
		
	This reference
		this refers to the current object (the instance). It’s used to access the 
		class’s own fields or properties when there’s a naming conflict.
	
	public class Person               			// class
	{
		public string Name { get; set; }   		// property
		public int Age { get; set; }       		// property

		public Person()                			// default constructor
		{
		}

		public Person(string name, int age) 	// parameterized constructor
		{
			Name = name;              			 // set property
			Age = age;                			 // set property
		}

		public void Speak()           			 // method
		{
			Console.WriteLine("Hello");
		}
	}
